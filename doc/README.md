# Documentación del repositorio

Este árbol contiene la documentación mantenida para el proyecto `ato-ai-skill-mem`:

- [`project/`](project/README.md): propósito y organización del repositorio.
- [`memory/`](memory/README.md): separación entre documentación, memoria del
  proyecto y estructura base de `wiki/`.
- [`skill/`](skill/README.md): propósito, componentes y empaquetado de las
  skills del repositorio.
- [`memory/history/`](memory/history/): registros históricos trasladados desde
  la antigua wiki del repositorio.

Los archivos bajo `memory/history/` preservan el historial del proyecto. No
son registros de una instancia activa y no deben copiarse como contenido
inicial a `wiki/`.
