# Historial trasladado de la wiki

Este archivo conserva el contenido que antes ocupaba la wiki del repositorio.
Se trasladó para separar la memoria de instancia de la documentación e
historia del producto. Los archivos de dominio conservan su estructura y sus
registros originales para mantener procedencia y enlaces relativos entre
ellos.

Estos materiales son históricos y no se cargan como memoria activa. La wiki
operativa de cada instalación empieza vacía, con el layout y las reglas
generales de este repositorio.

- [`domains/`](domains/): paquetes históricos `engineering-prompts` y
  `project-context` con sus índices, reglas, metadata y registros.
- [`action-log.md`](action-log.md): bitácora de operaciones anterior al
  traslado.
